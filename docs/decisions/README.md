# 决策索引

> 一句话：15 篇 ADR 的编号、标题、状态、取代关系与现行指针。

架构决策记录（ADR）回答「当时为什么这么选」，`docs/约束索引.md` 回答「现在的规则是什么」。本表只做一件事：让读者不必逐篇读正文，就能看出哪条还现行、哪条被后来的一篇更正、现在该去哪份文件找规则。

**状态四档**：`现行` = 今天重做这个决定仍会这么定；`被取代` = 已由另一篇替代（`取代关系` 列必须指向那一篇）；`仅历史` = 只保留当时的取舍，不再驱动任何规则；`未启动` = 决定已经下了，但计划中的那一段还没开始。括号里只写补充事实，不改变档位。

**关系与指针**：`取代关系` 只写 ADR 编号；`现行指针` 写这条决定今天落在哪个文件或哪条约束上。ADR 正文顶部保留 `- 状态：` 与 `- 关联：` 两行作为历史留痕（早期篇目把「关系」写作「关联」）；状态与关系的表格视图只在本表维护，新增或改判一篇时同步这一行。

`WP1`–`WP4`、`P0-5`、`P1-5`、`P2-4` 这类编号是**历史执行批次或分期**，不是未来指针；正文保留它们只为交代当时的上下文。
